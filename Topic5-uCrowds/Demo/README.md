This folder contains the demo files that we refer to in our report. 

The **Data** folder contains the  `Huntenpop_demo.scx` example SCX file. The rest of the files are all JSON-FG files, that represent the layers that the SCX file refers to.

The **Results** folder contains images of the export and import results. Additionally, the *Example density WMS stream (QGIS)* image demonstrates how the crowd density data from this demo project could be streamed to third-party GIS clients.
